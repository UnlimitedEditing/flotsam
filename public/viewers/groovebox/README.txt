Score player used by Flotsam's "Open score" button.

studio.html  is a patched copy of the Groove Box "Score Studio" (https://github.com/UnlimitedEditing/groovebox, MIT),
             generated by scripts/vendor-groovebox.py. The changes are listed in the comment at the top of the file.
vendor/      pako 1.0.11 (MIT + zlib), upng-js 2.1.0 (MIT), abcjs 6.4.4 (MIT), unmodified, pinned.
licenses/    the licence texts.

This folder is loaded only when a score is opened, and is not part of the offline install (vite.config.ts globIgnores).
